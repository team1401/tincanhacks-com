What "shipped" actually means

2026-10-05

FieldNotes is the daily-logging app I built with Helix for the technicians at PGTEK. Early October was mostly release engineering on it, and the most useful artifact wasn't code. It was a checklist that forced me to admit how many steps sit between "the build finished" and "it works on the phone."

The week started with a bug report: some daily entries had missing dates. The fix was a date-boundary patch in the entries router, plus a second fix for logging out in a way that preserved device reminders. Both got patched on the worktree, verified against live entries, then rolled into the 1.0.5 builds.

Here is the actual release record for 1.0.5, kept as a markdown file in the workspace:

iOS 1.0.5 (3), EAS build 53a96b89..., submission 9bb50d41...
  ASC build readback: VALID, internalBuildState IN_BETA_TESTING
Android 1.0.5 (6), EAS build 880eabd5...: FINISHED
  AAB sha256 1f795923...
  Play track readback: Active, latest release 6 (1.0.5),
  available to internal testers
  Only warning: missing deobfuscation file (non-blocking)

Every line there is a readback, not a claim. We query the App Store Connect and Play Console state after each step and write down what came back. The source commit hash is recorded even though the repo has no remote configured, because "we committed something" is not verifiable otherwise.

On October 5 the next release, 1.0.7 with a travel-timezone fix, got a release gate handoff. The gate splits the pipeline into five separate states: native build finished, store submission, distribution, install, and acceptance on a physical device. At handoff time only the first was true, and the document says so in plain words. The other four are marked unverified until someone proves them. It also defines small physical-device acceptance tests, the kind you can actually run in one sitting.

I used to say "shipped" the moment a build said FINISHED. That habit caused most of the surprises I've had with mobile releases. A finished build is one fact about four files and three consoles. Now the handoff answers the question before anyone has to ask it: what is proven, what is claimed, and what nobody has tested yet.
