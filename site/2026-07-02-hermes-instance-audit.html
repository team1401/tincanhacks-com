Auditing the Agent

2026-07-02

On July 2 we ran a full audit of the Hermes instance on the Mac. Same instinct as auditing a server you've been SSH-ing into for months: at some point you stop poking at it live and just read everything. The writeup came out six pages long. Here's the shape of it.

Disk first. The backups folder held 38 GB: four pre-update zips, the oldest from May. The retention setting kept five, and a pending update meant a fifth multi-gigabyte zip was queued to arrive. We deleted the three oldest, kept the newest, and set backup_keep from 5 to 2. Disk went from 82 percent to 75 percent, about 34 GB reclaimed once we also removed 2.6 GB of old migration data and a 149 MB stale cache. The workspace itself had 58 root entries untouched since June 1. They moved to a dated _archive folder with a manifest instead of the trash. Nothing deleted that day that couldn't be found again.

Then the logs, which is where it gets good.

The dashboard had been crash-looping every 10.5 seconds since May 18. Nineteen thousand log entries. It was trying to bind a Tailscale IP that wasn't assigned anymore, and even if it had bound, a non-loopback bind now requires an auth provider that nobody had configured. A crash loop that size is invisible until you count it, because each individual crash looks fine.

The model quota was the other quiet failure. 669 HTTP 429s on the subscription endpoint, and 149 cron jobs that had hard-failed over time, including the allowance monitor itself. The fix was a fallback chain so a quota wall downgrades instead of killing the job:

fallback_providers:
  - provider: openai-api    # per-token billing, bypasses plan quota
    model: gpt-5.5
  - provider: local-ollama  # last resort
    model: qwen3:8b

Smaller finds: a file-descriptor exhaustion event on July 1 that failed 37 scheduler ticks and dropped one inbound message before self-recovering, with 86 "unclosed client session" warnings pointing at a leak. Home Assistant auth broken since around June 22, 163 auth_invalid errors. A config line naming a browser plugin that isn't installed, warned about 2,580 times.

The open list at the end was longer than the closed one. Token refreshes, a possible duplicate bot instance, the pending update. That's normal for an audit. The value was never finishing it. The value was knowing exactly what's still broken, in writing, with sizes attached.
