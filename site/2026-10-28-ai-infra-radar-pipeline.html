A daily radar for desktop AI hardware that checks its own citations

2026-10-28

I care about a narrow slice of tech news: small desktop boxes for local AI inference, things like the DGX Spark and the GB10 machines from various vendors. The problem with following it is that aggregators repost each other, and an LLM asked to summarize the news will confidently invent headlines that never existed. So Helix and I built a pipeline where the summarizer can't get away with it.

Every morning at 7:50 a cron job runs a fetch script. It pulls six RSS feeds (TechCrunch AI, The Verge AI, MIT Tech Review, the Google AI blog, the NVIDIA blog, and one AI news site) and adds Bing News RSS endpoints for nine pinned queries:

queries = ['"DGX Spark"', '"GB10" NVIDIA', '"DGX Station"',
           '"RTX" workstation local AI',
           'Apple "Max" "AI" local inference',
           'llama.cpp MLX Ollama security vulnerability',
           'GB10 Dell Acer ASUS Gigabyte HP Lenovo MSI PNY',
           '"Apple Silicon" local AI October 2026']
feeds += ['https://www.bing.com/news/search?q=' +
          urllib.parse.quote(q) + '&format=rss' for q in queries]

The script fetches everything in a thread pool, parses both RSS and Atom formats, and keeps only entries whose pubDate falls inside a strict 48-hour window. Bing's redirect links get unwrapped to the real URL. The output is a JSON file of sources, and the briefing gets written from that file. If a headline isn't in the JSON, it doesn't exist.

The briefings themselves have house rules. Each item gets a "why it matters" line and a reliability caveat. The November 1 edition covered a first-hand report of running a quantized model on an ASUS GX10 at 1,450 tokens/second prefill. The briefing said, in effect: these are one user's numbers, not a reproduced benchmark, and the author hasn't shown the quantization preserves output quality. It also noted that official DGX Spark support was announced October 27, outside the window, so it was mentioned with a date instead of smuggled in as news.

The whole thing is maybe a hundred lines of Python plus a prompt. The discipline it enforces is worth more than the code: a fixed window, a fixed source list, and a rule that every claim traces back to a fetched file.
