# tincanhacks.com

Personal blog / project site for Brian Smith. "Tin Can" = the 1979 Airstream Sovereign;
"hacks" = the tech and AI work done from it (and from the shop, the truck, and wherever the
rig is parked).

Layout:
- `content/posts/*.md` — one markdown file per post, YAML frontmatter (title, date, category, summary)
- `build.py` — generates `site/` (static HTML, no framework)
- `site/` — generated output, published via GitHub Pages (tincanhacks.com)

Backfilled history covers April 2026 forward, the start of the verifiable Helix session record.
